## About

When2Talk investigates **when a proactive in-car agent should communicate with passengers during automated driving**.

The study compares:

- **Event-triggered communication (ET)**, where the agent communicates when a predefined driving event occurs.
- **Context-sensitive communication (CS)**, where the agent adapts whether and when to communicate based on the driving event and passenger context.

The study is implemented in CARLA with an immersive VR passenger setup.
